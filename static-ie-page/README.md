# 变电站监控信息样本库管理 - 静态页面

## 项目说明

这是一个完全静态的HTML页面项目，完全兼容Internet Explorer浏览器。页面展示了变电站监控信息样本库管理界面，包含：

- 左侧导航菜单
- 顶部头部栏
- 筛选搜索栏
- 操作按钮区域
- 数据表格
- 分页控件

## 技术特点

### IE兼容性
- 完全兼容IE8及以上版本
- 使用传统CSS布局（float布局）
- 避免使用CSS3新特性
- 使用HTML5 shiv和Respond.js polyfill支持旧版IE

### 样式特点
- 颜色方案参考自原有UI项目（bdfzfx-admin/ui）
- 主色调：深蓝色导航栏（#304156）
- 按钮颜色：Element UI蓝色（#409EFF）
- 字体：Helvetica Neue, Microsoft YaHei等系统字体

### 静态展示
- 无JavaScript动态功能
- 纯HTML+CSS实现
- 所有数据均为静态展示
- 按钮和链接无实际功能

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件即可查看页面
2. 支持所有主流浏览器，特别是IE8+
3. 无需任何服务器或构建工具

## 样式参考

页面样式参考了原始UI项目的设计规范：
- 颜色变量来自 `ui/src/assets/styles/variables.scss`
- 布局结构参考 `ui/src/views/system/all/index.vue`

## 注意事项

1. 所有功能均为静态展示，无实际交互功能
2. 数据表格中的数据为示例数据
3. 按钮点击无实际功能
4. 分页控件为静态展示，无法实际切换页面
5. 如需添加动态功能，需要引入JavaScript框架（如Vue.js）和相应的后端接口

## 后续开发建议

如果需要将静态页面转换为动态页面，建议：
1. 使用Vue.js作为前端框架
2. 参考 `ui/src/views/system/all/index.vue` 的实现
3. 添加API接口调用
4. 使用Element UI组件库
5. 参考原有项目的路由和状态管理方案
